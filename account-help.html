Wantt

Account and data help

Check which library you’re using

You can use Wantt without signing in. Your guest library and your signed-in library are separate. To check which one you’re using, open Profile and look under Account. If you use Sign in with Apple, check that you’re using the account you expect.

If Wantt offers Review guest data after you sign in, review the items shown before choosing what to move.

If a save is missing

Check the iPhone and the library where you made the save. Some links, notes and plans may be stored only on that iPhone. If you’re unsure where an item is stored, ask for help before reinstalling Wantt or switching devices.

Account and data controls

Signing out hides your account library on this iPhone. Requesting deletion is a separate action. Use the controls shown in Wantt and follow the instructions in the app. If you can’t find a control or have a question about a status message, contact Wantt support.

See the privacy notice for information about data use.
